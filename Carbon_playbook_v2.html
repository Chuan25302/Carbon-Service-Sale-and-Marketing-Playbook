โครงการ Business Development Services (BDS) ของ สำนักงานส่งเสริม SME (OSMEP) — ให้เงินอุดหนุน 50% ของค่าที่ปรึกษา สูงสุด ฿200,000 ต่อราย

SME ส่วนใหญ่ ไม่รู้ว่ามีโครงการนี้ — การที่หมอโรงงานช่วยยื่น = ลดราคาได้ทันที 50% ทำให้ Objection เรื่องราคาหมดไป

ตัวอย่าง:
CBAM Package ฿249,000 → หลัง OSMEP = จ่ายจริง ฿124,500
ROI จากชิปเมนต์แรก = ประหยัด ฿400,000+ = คืนทุน 3× ทันที

วิธีใช้ใน Sales Process

  1. เปิดด้วย ROI Story ก่อน — ไม่ใช่ราคา
  2. เมื่อลูกค้า Hesitate เรื่องราคา → แนะนำ OSMEP ทันที
  3. Assistant ช่วยเตรียมเอกสารยื่น (ลด Friction ลูกค้า)
  4. ราคาสุทธิลูกค้าจ่าย = ครึ่งเดียว
  5. ปิด Deal ง่ายขึ้น — Objection หายไปทันที
Sales Script: "เราช่วยยื่น OSMEP BDS ให้ครับ — ราคาจริงที่คุณจ่ายแค่ ฿124,500 และคืนทุนได้จากชิปเมนต์แรกเลย"

SPIN Selling — คำถามที่ทำให้ลูกค้าตัดสินใจเอง
SPIN = Situation → Problem → Implication → Need-Payoff — ใช้คำถามนำ ไม่ใช้ Hard Sell ลูกค้าไทย (โดยเฉพาะเจ้าของโรงงาน) ตัดสินใจเองหลังเห็นภาพชัดด้วยตัวเอง
S — Situation Questions
ถามเพื่อเก็บข้อมูล — ไม่ถามมาก จะดูว่า Research มาไม่ดี
  • →"ตอนนี้โรงงานส่งออกไป EU ปีละประมาณกี่ตันครับ?"
  • →"ปัจจุบันทำ GHG Inventory หรือ Carbon Footprint ไว้บ้างไหมครับ?"
  • →"ลูกค้า EU ถามเรื่อง Carbon Data มาบ้างไหม?"
P — Problem Questions
ถามให้ลูกค้าพูดปัญหาออกมาเอง — มีพลังกว่าเราบอกเอง
  • →"ถ้ายังไม่มี Verified Carbon Data ตอนนี้ คิดว่าจะกระทบ Order ไหมครับ?"
  • →"ถ้าต้องใช้ Default Value ของ EU คิดว่าต้นทุนจะเปลี่ยนแปลงอย่างไร?"
  • →"ตอนนี้มีทีมภายในที่ดูแลเรื่อง Carbon Compliance ไหม?"
I — Implication Questions
ขยายผลของปัญหา — ทำให้ลูกค้าเห็นว่า "ไม่ทำ" มีผลกระทบระยะยาว
  • →"ถ้าคู่แข่งเริ่มมี Verified Carbon ก่อน คิดว่าจะกระทบราคาและ Order ของคุณยังไงครับ?"
  • →"CBAM Default Value จะปรับขึ้น +10% ทุกปี — ถ้าปล่อยไป 3 ปีต้นทุนเพิ่มขึ้นเท่าไหร่?"
  • →"ถ้าลูกค้า EU เริ่ม Switch ไปซื้อจาก Supplier ที่มี Carbon Data ครบ โรงงานจะรับมือได้ไหม?"
N — Need-Payoff Questions
ให้ลูกค้าพูด Solution เอง — มีพลังมากที่สุด ปิดการขายตัวเอง
  • →"ถ้ามี Verified Carbon Data ครบ คิดว่าจะช่วยเรื่อง Order และต้นทุนได้แค่ไหนครับ?"
  • →"ถ้าเราช่วยทำให้เสร็จภายใน 6 สัปดาห์ ทันก่อน Q3 Shipment — คุ้มค่าไหม?"
  • →"ถ้าลดต้นทุน CBAM ลงได้ ฿400,000+ ต่อปี ค่าบริการ ฿124,500 (หลัง OSMEP) ถือว่าคุ้มไหมครับ?"
